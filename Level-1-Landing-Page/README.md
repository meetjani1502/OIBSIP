# TechNova – Landing Page

## About the Project

TechNova is a responsive technology company landing page created as part of the Oasis Infobyte Web Development and Designing Internship.

## Technologies Used

- HTML5
- CSS3

## Features

- Responsive navigation bar
- Hero section
- About section
- Services section
- Contact section
- Footer
- Mobile-friendly layout

## How to Run

1. Clone the repository.
2. Open the Level-1-Landing-Page folder.
3. Run:

   python3 -m http.server 5500

4. Visit http://localhost:5500 in your browser.
