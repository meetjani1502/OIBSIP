# Dr. A.P.J. Abdul Kalam Tribute Page

A responsive tribute website dedicated to Dr. A.P.J. Abdul Kalam.

## Features

- Biography section
- Life journey timeline
- Major achievements
- Inspirational quote
- Responsive layout
- Smooth scrolling

## Technologies Used

- HTML5
- CSS3

## How to Run

1. Open the project folder in VS Code.
2. Open index.html in your browser.
3. Make sure you have an internet connection to load the portrait image.
