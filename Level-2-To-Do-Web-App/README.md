# TaskFlow – To-Do Web App

## Overview

TaskFlow is a responsive To-Do Web Application developed as part of the Oasis Infobyte Web Development and Designing Internship.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Filter All, Active and Completed tasks
- Clear completed tasks
- Save tasks using browser Local Storage
- Responsive design

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run `python3 -m http.server 5500`.
4. Open `http://localhost:5500/` in your browser.
